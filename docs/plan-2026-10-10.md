## What might be missing (open questions for Harold)
1. Drag handle. If the group header is hidden for single-tab groups, the tab is gone and so is the drag source. The pill must become the drag handle or DnD is lost.
2. Maximize. Dockview has `api.maximize()` per group; worth a pill menu item on mobile.
3. Pop-out windows do not share the json-bus (in-process only). A popped-out 3D-Inspect will not follow selection. Either accept it, or relay bus events over Tauri events (the OSC path already does this).
4. Toolbar visibility should persist per pane in panel params, or it resets on reload.
5. Keyboard: pill menu needs focus/Escape handling; mobile needs long-press for the menu.
6. "+" clone action in the current left header slot: where does it go when the header hides? Pill menu, probably.
7. Status bar currently carries the only connected/decoupled toggle; when the layout is one big 3D pane on a phone, that bar costs 40px. Could move into the pill menu.
